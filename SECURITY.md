# Security policy

## Supported versions

Security fixes are provided for the latest release of `litestar-keycloak-admin`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately by email to
`alexkorolex@bk.ru` with:

- the affected package version;
- a description of the impact and reproduction steps;
- any suggested mitigation, if known.

You should receive an acknowledgement within seven days. Please allow time for a fix and a
coordinated release before disclosing the issue publicly.
